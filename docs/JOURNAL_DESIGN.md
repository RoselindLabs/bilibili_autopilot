# 浏览手记页面

## Direction contract

THESIS：回答“她今天读到了什么、留下了什么想法”。按天连读，长短自然的正文优先，视频为引用；不以评论任务表格作为主页面。

OWN-WORLD：沿宿主maibot主题变量、正文系统字体与原管理桥；背景与展开内容只用相邻色阶，来源链接用主色，无卡片阴影、装饰统计或假纸张。使用场景是手机或电脑随手回看，跟随用户当前明暗主题。

STORY：进入当天手记 → 阅读感想 → 展开依据或关联旧感想 → 选择日期回看。账号/暂停/异常仍可找到；0.10.1按用户反馈将历史文字列表和管理操作收进底部折叠区，侧栏仅留手记。

FIRST VIEWPORT：标题与运行状态，紧凑日期/搜索工具，第一段真实感想及其来源。正文最大78ch；手机单列16px边距，44px触控控件，长标题与正文换行。

FORM：用户已在三种预览中选定“按天连读”（另外两项为时间旁注、感想与来源分栏）。seed:dd930d4e6c5ddb08；方向服务不可用，采用本地结构方案。Taste true-black-flat/417882212保留宿主色彩与字体，取同底色、无侧栏的阅读框架，不固定成暗色。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 真实状态与交互

无记录、未登录、读取中、失败、暂停、无感、未读到正文各有独立表达。来源及感想以纯文本渲染，链接只由校验后的BV构造。页面读操作不生成内容，手记正文不写浏览器持久存储。最新查询代次拒绝旧响应，切换账号清理旧视图。素材提供/任务未知与确认送达分别表述。

设计示例使用合成海洋生物资料，不作为线上活动历史。生产页面没有样例数据、外部字体或装饰图片。
